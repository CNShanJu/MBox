# MBox（极光影院）重设计 — 功能与交互逻辑文档

> 版本：v2.0 重设计稿 ｜ 配套设计文件：MBox App 重设计（Ardot）
> 设计基调：极光影院 Aurora Cinema — 纯黑底 `#000000`，极光渐变青 `#35E0FF` → 紫 `#7C6CFF` 仅用于主 CTA / 进度条 / 激活态

---

## 0. 产品定位与本次重设计决策

MBox 是一款基于爬虫源配置（spider jar + JSON 源）的本地聚合播放器。内容来自用户自行配置的采集源，本身不生产内容。重设计在保留"多源聚合"核心能力的前提下，明确以下产品决策：

| # | 决策 | 说明 |
|---|------|------|
| 1 | **样式走主题配置文件** | 全部颜色/圆角/背景来自 `assets/theme/` 下的 theme.json，支持用户自定义与背景图（详见第 1 章） |
| 2 | **不做弹幕** | 移除播放器弹幕开关、弹幕设置项、弹幕输入 UI；播放设置面板不再出现任何弹幕条目 |
| 3 | **不做用户体系** | 移除登录/注册/VIP/头像/云端同步；"我的"页改为本地模式（本地数据 + 本地设置入口） |
| 4 | **搜索对齐真实多源逻辑** | 点播搜索为多源并发搜索，结果按源分组、按返回顺序追加、**不按片名去重**；直播源不参与搜索（详见第 4 章） |
| 5 | **补齐历史页** | 自适应网格（3:4 海报卡），卡片带源徽章 + "第 N 集/看完 xx%" 备注；长按进入多选管理（详见第 5 章） |
| 6 | **补齐弹窗与抽屉** | 8 个浮层组件全部出稿：换源抽屉、播放设置（底部/右侧）、确认弹窗、下载选集、选集、画面缩放菜单、详情抽屉（详见第 6 章） |
| 7 | **补齐大屏适配** | 平板竖屏（侧边导航 + 宽幅双列）、平板横屏（直播三栏 / 播放器全屏 + 右侧设置抽屉）（详见第 7 章） |

**全局交互规则**

- 全局采用 AutoSize 360dp 基准缩放；平板不额外放大，而是改布局（侧边栏常驻、双列、宽幅内容）。
- 返回手势/返回键：浮层优先关闭自身（抽屉 → 下拉或点遮罩；弹窗 → 点遮罩或取消），其次退出当前页。
- 所有列表页支持下拉刷新（源管理、搜索结果、直播列表除外直播由源推送刷新）。
- 空/错状态统一为"插画 + 主文案 + 次文案 + 主 CTA"结构；加载态统一骨架屏。

## 1. 主题系统（theme.json）

### 1.1 配置结构

主题文件位于 `app/src/main/assets/theme/themes/<明暗>/<主题名>.json`，用户自定义图片存放于 `theme_bg/*.webp`。配置分四组：

**颜色组（11 键）**

| 键 | 用途 | 默认值（暗色） |
|---|---|---|
| `bg_body` | 页面最底层背景 | `#141414` |
| `bg_surface` | 卡片/列表 surface | `#1C1C1E` |
| `bg_card_alpha` | 半透明卡片底（毛玻璃层级） | `rgba(255,255,255,0.06)` |
| `bg_float_alpha` | 浮层（抽屉/弹窗）底色 | `rgba(28,28,30,0.92)` |
| `brand` | 品牌主色 | `#4291FF` |
| `text_highlight` | 高亮文本/链接 | `#4291FF` |
| `btn_confirm_bg` | 确认按钮底 | `#4291FF` |
| `btn_confirm_text` | 确认按钮文字 | `#FFFFFF` |
| `success` | 成功态（下载完成等） | `#34C759` |
| `switch_thumb` | 开关滑块 | `#FFFFFF` |
| `download_active` | 下载中激活态 | `#4291FF` |

**圆角组**：`radius_dialog: 20` / `radius_card: 18` / `radius_btn: 24` / `radius_background: 26`

**背景组 `background` / 启动图组 `splashBackground`**

```json
{
  "mode": "default | solid | image",
  "zoom": "fill | fit | stretch",
  "anchor": "center | top | bottom",
  "alpha": 0.0-1.0,
  "scrim": 0.0-1.0
}
```

### 1.2 优先级与生效规则

**优先级：用户设置 > 主题文件默认值 > 纯色兜底。**

1. `mode: default` — 跟随主题明暗的纯色（bg_body）。
2. `mode: solid` — 用户指定纯色。
3. `mode: image` — 用户自选背景图（webp），`zoom` 决定填充方式，`alpha` 控制图片不透明度，`scrim` 在图片上叠加黑色遮罩保证文字可读性（列表页建议 scrim ≥ 0.4）。
4. 启动图（splashBackground）与背景图规则一致，独立配置；冷启动先展示启动图，进入首页后交叉淡入全局背景。

### 1.3 用户自定义入口

设置页 →"主题与背景"：

- 主题选择器：暗色（默认）/ 明色两套；明色套件同样输出全部 11 色 + 圆角。
- 自定义颜色：11 个色键全部开放取色器，修改后实时预览（首页/详情/设置三采样卡）。
- 背景图：从相册选图 → 裁剪（16:9 / 9:16 / 原图）→ 选择填充方式与遮罩强度 → 保存。
- 一键重置：恢复 theme.json 默认值。

### 1.4 设计系统中的落地

设计系统页第 09 节包含：theme.json 键位对照表、主题选择器 mock、背景图参数示意（zoom/anchor/alpha/scrim 四态预览）。所有界面稿的颜色/圆角均从 token 取色，不写死（渐变青→紫除外，为品牌资产）。

## 3. 核心流程详述

### 3.1 首页

| 元素 | 交互 |
|---|---|
| 搜索入口 | 点击进入搜索输入态；右侧胶囊显示源状态（绿点=全部正常，黄点=部分异常，红点=全部异常），点击跳源管理 |
| Hero 横幅 | 5s 自动轮播；左滑手动切换；点击进入对应详情；指示器为小短条 |
| 继续观看 | 横滑列表；卡片含进度条（渐变）+"第 N 集"角标；点击续播（断点续播），长按可移除单条 |
| 分类横区 | 横滑卡片；"全部"进入片库并预选该分类；卡片点击进详情 |
| 下拉刷新 | 重新拉取首页推荐（不清空缓存，先展示旧内容再替换） |

### 3.2 直播

- 频道分组栏常驻左侧；点击分组滚动定位到对应分组头。
- 频道项显示：台标、频道名、正在播出的节目名、播出进度条。
- 点击频道：底部/中部播放器起播，起播前展示"线路检测中"骨架；播放中显示 LIVE 徽章 + 码率。
- 换台：上下滑动列表自动换台（焦点跟随），或播放器左右箭头。
- 频道不支持搜索（与代码一致），仅支持分组浏览与收藏常用频道。
- 长按频道：加入/移除"常用"分组。

### 3.3 片库

- 顶部筛选行：类型 chip 多选（选中态渐变描边）；排序切换（最新/最热/评分）。
- 结果瀑布网格 2 列；无限滚动，触底加载，骨架屏占位。
- 筛选条件变化时重置到第一页，保留滚动位置记录。

### 3.4 详情页

| 区域 | 交互 |
|---|---|
| 播放区 | 简介态为 16:9 预览窗（点击起播并转全屏）；起播后窗口常驻播放，选集/换源不打断播放 |
| 信息区 | 评分（大号数字）+ 年份 · 类型 · 集数 · 地区；简介默认 3 行，点击"展开"全文，"收起"回到 3 行 |
| 操作区 | 主 CTA"播放 第 N 集"（记住上次观看到集）；次操作：收藏（星形，激活态渐变填充）、下载（进下载选集抽屉）、分享（复制链接/二维码） |
| 换源条 | 横向源徽章（源A 蓝光/源B 高清/源C 标清）；当前源高亮；点击弹出换源抽屉（QuickSearch）展示各源解析状态与速度，切换后重新拉取详情与选集 |
| 选集区 | 线路 Tab（线路1/2/3）+ 剧集网格；当前集渐变填充；"倒序"切换排序；超出 30 集折叠"更多" |
| 收藏 | 收藏/取消收藏即时反馈（图标弹跳 + toast）；收藏结果进"我的-收藏" |

### 3.5 播放器

**竖屏**：顶部返回 + 标题 + 更多（进详情抽屉）；中部大播放键 + 快进/快退 10s；底部进度条（渐变，可拖拽）+ 时间；功能条：剧集 / 倍速 / 字幕 / 锁定 / 全屏。

**横屏**：手机横屏全屏为 812×375（见 `core-05-landscape-fullscreen.png`）——顶栏（返回、片名 + 「第 N 集 · 源 · 清晰度 · 码率」、投屏、更多）；中央控制（快退、播放/暂停大按钮、快进，垂直居中）；底部 HUD（当前时间 + 渐变进度条（缓冲段/已播段/滑块）+ 总时长；功能条：剧集 / 倍速 1.0x / 字幕 / 锁定 / 退出全屏）；横屏下隐藏状态栏与底部 Tab（沉浸式），此时末位按钮语义为「退出全屏」（收起 HUD 或返回竖屏）。设置抽屉从右侧滑出（320dp，见 `core-06-landscape-settings.png`）：倍速六档 chips + 设置行（画面缩放 / 跳过片头片尾 / 播放器内核 / 解码方式 / 字幕）+ 底部「选集 / 下载」双按钮；播放画面不被遮挡，点遮罩关闭。点功能条「剧集」或抽屉内「选集」→ 底部通栏选集抽屉（见 `core-07-landscape-episodes.png`）：标题（选集 · 共 N 集 · 倒序 · 关闭）+ 线路 chips + 双行 6 列剧集网格（当前集渐变高亮），点选即切集，抽屉高度自适应内容。平板横屏播放器布局见第 7 章。

**播放控制逻辑**

- 起播流程：解析地址（loading）→ 起播 → 记录播放位置（每 5s 落库）→ 记录观看历史（含源、集数、进度）。
- 断点续播：历史卡片点击 → 从上次位置续播；进度 > 95% 视为看完，下次从头播放并提示"已看完，重新播放"。
- 倍速：0.5x–3.0x 六档；长按画面 = 2x 临时倍速，松开恢复。
- 手势：左右滑 =  seek；左半屏上下滑 = 亮度；右半屏上下滑 = 音量；双指捏合 = 画面缩放。
- 锁定：锁定后仅响应解锁按钮，防误触。
- 播放失败：重试 2 次 → 仍失败提示"换源播放"（直达换源抽屉）。
- 线路切换：不清播放进度（同片同集优先），失败自动回落上一线路。

## 4. 多源搜索（对齐真实代码逻辑）

### 4.1 搜索流程

1. 输入关键词（防抖 300ms）→ 展示联想建议（来自 iQIYI 建议 API + 本地历史）。
2. 点击"搜索"或回车 → 多源并发搜索：
   - **4 线程并发、两波分发**：第一波向全部启用点播源发请求；返回的源进入第二波（翻页/续查）。
   - 结果**按源分组**展示，组内按返回顺序追加，**不按片名去重**（不同源可能有同名不同版本，均展示）。
   - 直播源不参与搜索。
3. 慢源处理：超过 8s 未返回的源在结果流中显示"XX 仍在搜索…"骨架，返回后插入对应源分组。
4. 热搜词：来自 360 热词 API，输入态空查询时展示。

### 4.2 结果页交互

- 顶部：搜索框（可改词重搜）+ "找到 N 条 · 来自 M 个源"统计。
- 左侧源 Tab：`全部 N` + 每个源一个 Tab（含各自条数）；激活 Tab 过滤结果流。
- 结果卡片：海报 + 标题 + 评分/年份/类型/集数 + 简介摘要 + 源徽章 + "更新至第 N 集"。
- 上拉加载更多：**每源独立翻页**，触底时对当前可见源发起下一页请求；底部提示"上拉加载更多 · 每源独立翻页"。
- 点击卡片进详情（自动选中该结果所属源）。

### 4.3 搜索历史与联想

- 搜索历史：本地最多 30 条，最新在前；单条可删（左滑或长按），可一键清空（危险确认弹窗）。
- 联想态：空查询显示热搜 + 历史；输入中显示建议列表（关键词高亮匹配部分）；无建议显示历史。

## 5. 观看历史

### 5.1 列表

- 自适应网格：竖屏 3 列、平板 4 列；海报卡 3:4。
- 卡片信息：海报 + 底部标题 + **源徽章**（源A/源B/源C，标识该记录来自哪个源）+ 备注（电视剧"第 N 集"，电影/看完"看完 xx%"）。
- 失效源标记：源已被删除/禁用的记录，徽章显示"源未启用"（置灰），点击播放时提示先启用或切换源。
- 底部统计："共 N 条 · 自动保留最近 70 条"（超出自动淘汰最旧）。
- 点击卡片：断点续播。

### 5.2 多选管理

- 入口：左上角"多选"按钮或长按任意卡片进入。
- 进入后：卡片显示勾选态；顶栏变为"全选 / 完成"；底部操作栏：删除（红）、续播（主 CTA，单选时可用）。
- 删除：危险确认弹窗（"确定删除 N 条观看历史吗？删除后不可恢复"），确认后删除并退出多选。
- 清空：列表页右上角垃圾桶 → 危险确认弹窗（"确定清空全部观看历史吗？清空后不可恢复，下载中的任务不受影响"）。

## 6. 弹窗与抽屉（8 个浮层组件）

### 6.1 换源抽屉（QuickSearch，底部弹窗）

- 触发：详情页换源条点击、播放失败"换源播放"、播放中手动换源。
- 内容：标题"其他数据源相关搜索" + 关闭；顶部关键词 chip（当前片名 / 前传 / 纪实等关联词）；列表每行：源徽章 + 结果标题 + 类型·集数/时长 + 更新状态 + 右箭头。
- 交互：点击行 → 切换该源并重新拉取详情/选集，toast 反馈；下拉把手或点遮罩关闭；切换中源行显示 loading。

### 6.2 播放设置 · 底部面板（竖屏）

- 触发：播放器功能条"倍速/设置"。
- 内容：倍速六档 chip（0.5x/1.0x/1.25x/1.5x/2.0x/3.0x，当前档渐变）；设置行列表：长按倍速（当前值）、画面缩放（默认）、跳过片头/片尾（-30s/+90s，可调）、播放器内核（系统播放器/ExoPlayer/IjkPlayer）、解码方式（硬解优先/软解优先）、字幕（未加载 → 加载本地字幕）、音轨（默认/多音轨切换）、后台播放开关；底部双按钮：重播 / 刷新。
- 交互：点遮罩或下拉关闭；开关即时生效；内核/解码修改后提示"下次起播生效"。

### 6.3 播放设置 · 右侧抽屉（横屏）

- 与 6.2 同内容，右侧滑出；播放画面不被遮挡（抽屉宽 320dp）；倍速 chip 行 + 设置行 + 底部"选集/下载"双按钮；点击遮罩关闭。

### 6.4 确认弹窗（危险操作）

- 结构：标题（加粗）+ 说明（危险后果，红字强调不可恢复）+ 双按钮（取消 / 确认，确认为红色描边或红底）。
- 应用场景：清空历史、删除历史多选、删除下载任务、清空搜索历史、移除源。

### 6.5 下载选集抽屉

- 触发：详情页"下载"按钮。
- 内容：标题"下载剧集"；剧集数字网格（多选，选中渐变）；底部：已选 N 集 + 预计体积（如 1.4GB）+ 清晰度选择（源A 蓝光）+ 主 CTA"开始下载"。
- 交互：多选切换实时更新体积预估；开始下载后抽屉关闭，任务进下载管理；下载中同一集显示进度。

### 6.6 选集抽屉

- 触发：播放器"剧集"、详情页"更多"选集。
- 内容：标题 + 倒序切换 + 关闭；线路 Tab（线路1/2/3，当前源高亮）+ 剧集网格（第 N 集，当前集渐变）。
- 交互：点集数 → 切换播放（不清进度逻辑同 3.5）；线路 Tab 切换重新拉取该线路剧集列表。

### 6.7 居中菜单 · 画面缩放

- 触发：播放中双指捏合或设置行"画面缩放"。
- 内容：居中卡片：默认 / 16:9 / 4:3 / 填充全屏 / 裁剪 / 原始尺寸，当前项青色 + 对勾。
- 交互：点选即时生效；点遮罩或 2s 无操作自动关闭。

### 6.8 详情信息抽屉

- 触发：播放器顶栏"更多"、播放中上滑。
- 内容：小海报 + 标题 + 评分·年份·类型·集数·地区 + 播放地址（可复制）+ 简介全文 + 展开/收起；底部主 CTA"继续播放 第 N 集" + 收藏星钮。
- 交互：复制成功 toast；收藏即时反馈；点遮罩关闭（播放不中断）。

## 7. 大屏适配（平板）

代码现状：无 `layout-sw600dp` / `layout-land` 资源，全局 AutoSize 360dp。重设计按断点重排布局，而非等比放大。

### 7.1 平板竖屏（744×1000 基准）

- **首页**：左侧 72dp 侧边导航栏（图标 + 文字，常驻，选中态渐变）+ 宽幅内容区；Hero 全宽；继续观看与分类区双列网格；底部 Tab 栏隐藏（改侧边导航）。
- **详情**：左栏（440dp）播放与信息（播放窗 + 标题 + 操作 + 换源 + 选集），右栏简介与推荐（剧情简介 + 相关推荐列表，可独立滚动）。
- 其他页（搜索/历史/下载/设置）：双列网格 + 侧边导航；表单类页面限宽 560dp 居中。

### 7.2 平板横屏（1024×768 基准）

- **直播**：三栏结构 —— 频道分组栏（120dp）+ 频道列表（240dp，双行：频道名/节目）+ 沉浸播放区（剩余宽度，16:9 居中）；播放区含 LIVE 徽章、码率、中央控制、底部进度。
- **播放器**：全屏播放 + HUD；右侧设置抽屉（320dp）滑出，内容同 6.3；选集以半屏浮层展示（利用横屏宽度双列剧集）。
- 详情页横屏：左信息 + 中播放 + 右推荐三栏。

### 7.3 断点规则

| 宽度 | 布局 |
|---|---|
| < 600dp | 手机版（本设计默认稿） |
| 600–959dp | 平板竖屏（侧边导航 + 双列/宽幅） |
| ≥ 960dp | 平板横屏（直播/播放三栏，详情三栏） |

## 8. 状态与边界情况清单

| 场景 | 表现 |
|---|---|
| 无源/源全部失效 | 首页空态引导去源管理；源状态胶囊红点 |
| 部分源失效 | 胶囊黄点；源管理页标红该源；搜索结果只含可用源 |
| 搜索无结果 | 空态 + "换个关键词试试" + 热搜推荐 |
| 搜索源超时 | 结果流内"XX 仍在搜索…"骨架，返回后插入 |
| 起播失败 | 重试 2 次 → 提示换源（直达换源抽屉） |
| 断网 | 顶部 toast"网络已断开，展示缓存内容"；收藏/历史本地可读 |
| 下载中杀进程 | 任务持久化，重启后恢复，通知栏显示进度 |
| 存储不足 | 下载前校验，不足时弹窗提示并引导清理 |
| 历史超 70 条 | 自动淘汰最旧，底部统计提示 |
| 源被删除 | 历史/收藏/下载中该源记录标"源未启用"，不可直接播放 |
