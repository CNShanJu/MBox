# 新版设计参考 · MBox（极光影院）

MBox / TVBoxOS-Mobile 整体重设计的全部设计产出。设计源文件为 Ardot《MBox App 重设计》（画布可编辑），本目录为导出的静态参考图与文档。

- 品牌：极光影院 Aurora Cinema —— 纯黑底 `#000000`，极光渐变 青 `#35E0FF` → 紫 `#7C6CFF`（仅用于主 CTA / 进度 / 激活态）
- 字体：Noto Sans SC（正文）+ Inter SemiBold（数字，等宽对齐）
- 主题：样式走 theme.json 配置（11 色键 + 圆角组 + 背景图），支持用户自定义与背景图，详见设计系统与文档

## 核心设计决策

1. 无账号体系：不设用户/会员/云同步，本地模式（本地数据 + 设置入口）
2. 无弹幕：播放器与设置项均不含弹幕
3. 多源搜索：4 线程两波并发分发，结果按源分组、按返回顺序追加、不按片名去重；直播源不参与搜索
4. 主题配置化：用户设置 > 主题默认 > 纯色；用户背景图存 `theme_bg/*.webp`
5. 大屏适配：<600dp / 600–959dp / ≥960dp 三档断点，改布局结构而非等比放大
