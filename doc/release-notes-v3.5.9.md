## 新增功能
- **下载支持 fMP4(初始化段)与字节范围分片**:这类源以前直接提示不支持,现在能正常离线下载。
- **下载缺片自动去别的线路补**:同一集在其它线路切分一致、时间轴接得上时,自动把缺的几片补回来,不必整集重下。
- **下载限速**:设置页与下载页都能选「不限速 / 512KB/s / 1MB/s / 2MB/s / 5MB/s」,改完对正在下载的任务立即生效。
- **新增「网络连接不可用」页**:确实没网且正在取数据时才出现,网络恢复后自动返回;页面上的「我知道了」一段时间内不再打扰。
- 设置里新增「忽略证书错误」开关,个别证书异常的站点打不开时可临时打开(默认关闭)。

## 功能变更
- **安全 DNS 改完立即生效**,不用再重启应用;取数(源站请求)也一并跟随该设置。
- 添加订阅弹窗的「支持范围」说明移到订阅页右上角的「订阅提示」里,输入框回到简洁形态;设置页「局域网服务」「忽略证书错误」的说明改为**长按标题**查看。
- 订阅导入 / 导出这类耗时操作可以取消,取消按钮的大小与其它弹窗一致了。
- 开关的开启色改为绿色系(亮色下关闭态也更浅),订阅页顶部两个图标高度微调。
- 无痕浏览不再在设置行里写说明(行为不变:不记观看历史与搜索历史,收藏照常记录)。
- 直播页状态栏改为跟随主题(与详情页一致),不再是一条固定黑带;底部导航/导航栏保持深色。

## 问题修复
- **断网相关**:离线打开应用、从「网络不可用」页返回、恢复网络后首页/分类一直转圈或不出内容,已修好(该收尾的收尾、网络恢复会自动重新加载)。
- **连着 Wi‑Fi 但取不到内容时,不再每隔几秒闪一屏「网络不可用」**(DNS 被拦 / 安全 DNS 不可用 / 源站域名不存在都属于这种)。
- VPN、有线网络、蓝牙共享上网不再被误判成「没网」(此前这些环境下页面不会自动恢复)。
- 播放中(含小窗)遇到断网不再被整屏提示打断;后台下载续传、检查更新失败也不会再弹整屏页。
- **播放起播更稳**:修复 Exo 取流客户端缺失导致的每次起播失败,以及空地址、解码档位、进度条与控制器提示等一批问题。
- **修复 HLS 下载成品一直是 .ts**:重封装以前从未真正生效,现在能产出标准 MP4(少数不支持的源仍保留 .ts)。
- 修复下载把「没读完」当成读完、被中断却记成「已完成」、换线路时丢掉已下进度等问题。
- 修复部分源**分类筛选面板整片空白**(单个坏筛选项不再连累整个源)。
- 修复抓页面源**分类页数虚高**(把分类编号当成了总页数)、**GBK 老站内容乱码**、JS 源本地代理播放失败、部分源**首次加载卡死不返回**等问题。
- 修复搜索「一直搜索中」不收尾(某个来源出错时卡住)。
- 修复详情页顶部状态栏黑带、崩溃页图标多余灰影、下载页左滑操作区与条目圆角等界面问题。

## 体验与性能
- 搜索首屏更快:明显偏慢的来源排到后面单独跑,不再拖住首批结果。
- 下载完成通知会写明缺片情况;下载保存根目录名统一为 MBox。
- 改设置项真的生效了:IJK 解码器选择现在会落库,清缓存会真正删干净再提示,安全 DNS 选项不再越界。
- 本机服务端口被占用时会写明实际端口,方便定位"源里写死端口"的问题。

## 兼容性与注意事项
- 包名未变,可直接覆盖安装,无需卸载。
- 断网时列表可能仍显示「暂无数据」(与「源本身没内容」看起来一样),网络恢复后会自动重新加载。
- 少数第三方源把代理地址写死成 `127.0.0.1:9978`:如果你手机上这个端口被别的应用占用,这类源的代理播放会失败,属源自身问题。
