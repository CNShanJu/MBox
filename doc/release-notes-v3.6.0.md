## 新增功能

- 点击首页搜索框时，搜索框放大进入搜索页；返回首页时缩回原位置。
- 首页可选择订阅和数据源。未配置订阅、数据源无响应或网络不可用时，会显示对应提示。
- 订阅导入可识别更多视频源格式，订阅管理页也会列出订阅自带的直播源。

## 问题修复

- 调整主题应用方式：系统切换深色模式时保留当前选中的暗色主题配色，启动页面也使用当前主题的背景色。
- 修正部分自定义主题下按钮边框、圆角及亮暗图标不清楚的问题。
- 下载地址或鉴权信息过期时，改进刷新与重试；续传前核对分片信息，减少错误复用下载进度。
- 调整更新弹窗与“上次观看”提示的显示顺序，避免提示盖在弹窗上方。

## 体验与性能

- 优化播放器的音轨、字幕和手势控制，并改善退出播放时的资源释放。
- 下载保存到应用专属目录时，不再额外要求“所有文件访问”权限。
- 统一弹窗、抽屉和页面按钮的外观，让自定义主题切换后的显示更一致。
