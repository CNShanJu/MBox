# MBox 项目目录结构总览

> 目的：对整个 MBox 工程（仓库 `CNShanJu/MBox`，原名 TVBoxOS-Mobile / 工程名 TVBoxMobile，本地目录可能仍是 TVBoxOS-Mobile）做一次目录级的大概览，说明每个模块、每个包的职责与关键类，便于快速定位代码与理解架构。
> 适用版本：3.5.7（versionCode 64），Gradle 8.4 / AGP 8.2.2 / Kotlin 1.9.22，minSdk 24 / targetSdk 34。
> 说明：本文件随模块化重构（doc/module-refactor-design.md）持续更新；核心业务已拆为多个独立 gradle 模块，依赖方向自上而下（app → 业务 API → 业务实现 → 基础设施 → 纯模型）。

---

## 一、工程总览

```
MBox/                     # 仓库根(本地检出目录名可能仍是 TVBoxOS-Mobile)
├── app/                    # 主应用模块（唯一 application，UI 薄层；主题与公共资源已并入 app 的 res / assets/theme）
├── player/                 # 播放器内核模块：ijk / EXO（DKVideoPlayer 封装）+ 播放契约（引擎无关，与实现同模块）
├── common/                 # 全局共用：纯模型(bean) + 算法工具(AES/MD5/AdBlocker) + 系统状态(state)
├── core-storage/           # 存储基础设施：Room + PrefsDataStore（配置/缓存/历史/收藏）
├── core-network/           # 网络基础设施：OkGoHelper / HttpClient / OkHttp 客户端收口
# 主题/通用资源(原 ui-common/)已并入 app/src/main/res 与 assets/theme
├── log/                    # 日志中心：LogStore（Room 业务日志 + logcat 捕获 + 7 天）
├── spider/                 # 爬虫模块：爬虫契约(spiderapi 包，原 spider-api 随迁) + SpiderApi 门面 + JsLoader/JarLoader + 解析 + util.js
├── download/               # 下载模块：DownloadFacade + 任务对象化 + 调度/执行/策略/档案
├── thirdparty/             # 第三方归堆：TabLayout + ViewPager1Delegate + CustomActivityOnCrash(崩溃兜底页) + QuickJS(JS 引擎 + jniLibs)
├── doc/                    # 项目文档（md）
├── scripts/                # 构建辅助脚本（PowerShell: 资源命名校验；Python: SVG/PNG → Vector）
├── .github/workflows/      # CI 工作流（push main/v* 标签或手动触发 release 构建）
├── gradle/wrapper/         # Gradle Wrapper(8.4)
├── settings.gradle         # 模块声明（rootProject.name = "MBox"）
├── build.gradle            # 根构建脚本（插件版本、仓库、公共配置）
├── gradle.properties       # JVM 参数 / AndroidX / nonTransitiveRClass=false
├── mbox-release.jks        # release 签名文件（专属新库，不入库；本地经 app/keystore.properties 读取）
├── README.md / LICENSE     # 项目说明与协议
└── local.properties        # 本机 SDK 路径（不入库）
```

### 模块依赖关系

```
app ──┬──> player         # 播放内核 + 播放契约（依赖 common / core-storage / log）
      ├──> spider         # 爬虫契约 + 实现（依赖 common / core-network / core-storage / log / thirdparty）
      ├──> download       # 下载门面 DownloadFacade（依赖 common / core-network / core-storage / log / spider）
      ├──> core-storage   # Room + PrefsDataStore（依赖 common / log）
      ├──> core-network   # OkHttp 客户端收口（依赖 core-storage / log）
      ├──> common         # 纯模型 + 算法工具 + 系统状态（依赖 log）
      ├──> log            # 日志中心（不依赖本仓其它模块）
      └──> thirdparty     # 第三方归堆 TabLayout/CustomActivityOnCrash/QuickJS（不依赖本仓其它模块）

:app → 以上全部 8 个模块
```

依赖边（逐个 build.gradle 核对）：

```
:common        → :log
:log           → （无）
:core-storage  → :common, :log
:core-network  → :log, :core-storage
:thirdparty    → （无，纯第三方归堆）
:spider        → :common, :core-network, :core-storage, :log, :thirdparty
:player        → :common, :core-storage, :log
:download      → :common, :core-network, :core-storage, :log, :spider
:app           → :player, :common, :core-storage, :log, :core-network, :spider, :download, :thirdparty
```

| 模块                 | 类型        | namespace                         | 职责                                                                         |
| -------------------- | ----------- | --------------------------------- | ---------------------------------------------------------------------------- |
| `app`                | application | `com.github.tvbox.osc`            | 主应用：UI 薄层、页面、组合根（AppCompositionRoot）                          |
| `player`             | library     | `com.github.tvbox.osc.player`     | 播放器封装：ijk/EXO 双内核 + 第三方播放器跳转（含 player.api 播放契约）     |
| `common`             | library     | `com.github.tvbox.osc.common`     | 全局共用：纯模型（bean）+ 算法工具（AES/MD5/AdBlocker）+ 系统状态（state）  |
| `core-network`       | library     | `com.github.tvbox.osc.corenetwork` | 网络基础设施：OkGoHelper/HttpClient/OkHttp 客户端收口                       |
| `core-storage`       | library     | `com.github.tvbox.osc.storage`    | 存储基础设施：Room + PrefsDataStore（配置/缓存/历史/收藏）                   |
| `spider`             | library     | `com.github.tvbox.osc.spider`     | 爬虫实现：SpiderApi/JsLoader/解析/JS 运行时（含 spiderapi 爬虫契约）        |
| `download`           | library     | `com.github.tvbox.osc.download`   | 下载：门面/调度/执行/策略/档案/通知（实现收口 internal 包）                  |
| `log`                | library     | `com.github.tvbox.osc.log`        | 日志中心（LogStore/LogConfig/LogcatCapture）                                 |
| `thirdparty`         | library     | `com.angcyo.tablayout`            | 第三方归堆：TabLayout + CustomActivityOnCrash + QuickJS（不依赖本仓模块）   |

> 现状共 **9 个 gradle 模块**（`:app` / `:common` / `:core-storage` / `:player` / `:thirdparty` / `:log` / `:core-network` / `:spider` / `:download`）。
> 已完成的合并（包名不变，外部引用不受影响）：`:core-model` + `:core-utils` + `:state` → `:common`；`:spider-api` → `:spider`；`:player-api` → `:player`；`:crash` + `:TabLayout` + `:ViewPager1Delegate` + `:quickjs` → `:thirdparty`；`:ui-common` → `:app`（主题 JSON 在 `app/src/main/assets/theme/`，`generateThemeColors` 任务在 `app/build.gradle`，styles/colors/dimens/drawable/anim 在 `app/src/main/res/`）。

## 三、player 模块（播放内核 + 播放契约层）

> 原 `player-api` 模块已并入 `:player`：播放契约与内核实现同模块，契约包路径不变（`com.github.tvbox.osc.player.api`）；UI 只依赖契约，不直接依赖 MyVideoView/IJK/Exo 具体内核。内核（vendored `tv.danmaku.ijk.*` / `xyz.doikki.videoplayer.*`）与 `jniLibs` 同样在本模块。

```
player/src/main/java/com/github/tvbox/osc/player/api/
├── PlayerApi.java        # 播放统一门面（引擎无关契约：init/play/pause/seek/speed/scale/state/subscribe/release）
├── PlayerFactory.java    # 播放器工厂（注册表：playType → Provider；Media3 升级=新增 Media3Adapter 注册）
├── PlayConfig.java       # 播放配置门面（内核/渲染/缩放/步进/解码/缓存/后台播放/净化/倍速/字幕 12 项，自持+订阅）
├── PlayOptions.java      # 播放参数（url/headers/position/start 等）
├── PlayState.java        # 播放状态（引擎无关）
└── PlayListener.java     # 播放监听（状态/进度/缓冲/错误）
```

## 四、core-network 模块（网络基础设施）

> 原 `common` 模块已拆分：网络职责留 `core-network`，配置门面迁 `core-storage`，纯算法（AES/MD5/AdBlocker）随 `:core-model`/`:core-utils`/`:state` 一并合并进 `:common`（包名不变），事件已归位各业务模块。

```

    ├── FCallBack / HCallBack # 回调接口
    └── urlhttp/              # brotli 拦截器（internal BrotliSource）
```

## 十二、目录整理说明（最近一次）

- **空目录清理**：删除 `app/.../api`、`app/.../event`、`app/.../util/rsa`（对应实现已迁 spider/common 模块）；
- **类归位**：`LivePlayerManager`（原 bean 包）→ `util` 包（管理器非数据模型）；
- **死代码清理**：`ui/tv/QRCodeGen.java`（全仓库无引用，zxing 调用方自带生成逻辑）；
- **主题/公共资源归位**：`assets/theme/*.json`、`generateThemeColors` 任务与公共 res（styles/colors/dimens/drawable/anim）现全在 `:app` 内（`app/src/main/assets/theme/`、`app/build.gradle`、`app/src/main/res/`），原 `:ui-common` 模块已撤；
- **模块合并（现状 9 个）**：`:core-model` + `:core-utils` + `:state` → `:common`；`:spider-api` → `:spider`；`:player-api` → `:player`；`:crash` + `:TabLayout` + `:ViewPager1Delegate` + `:quickjs` → `:thirdparty`；`:ui-common` → `:app`（均包名不变，外部引用不受影响）。
- **发布体系下线**：删除 `gradle/publish.gradle`（GitHub Packages 发布脚本）与 `:player` 的 apply，CI 里对应发布步骤一并移除——9 个模块都是 app 内部模块（含 vendored :player/:thirdparty），没有对外发布物，权限同步收回 `packages: write`。
- **Release 正文规范**：CI 不再把 commit 标题直接当更新说明；用户可读说明写在 `doc/release-notes-<tag>.md`，缺失时正文只留 `<!-- dev -->` 围栏（App 更新弹窗自动剔除），并在 Actions 里给出警告（AGENTS §九）。
