### J.1 各主题键"管哪里"速查(验证时对照,免得把"白字看不见"当成没生效)

| 主题里的键 | 管什么 | 典型现象(设成不适合的颜色时) |
|---|---|---|
| 卡片与浮层底色 | 面的**颜色**(页面卡片/标题栏/底栏/搜索框 + 弹窗/抽屉/气泡 共用同一支色) | 设成红:整站泛红 |
| 卡片透明度 | 页面层(卡片、标题栏、底栏、搜索框、占位)的**不透明度** | 设 10:卡片几乎透明,露出底图 |
| 浮层透明度 | 弹起那一层(弹窗、抽屉、气泡、悬浮钮)的不透明度 | 设 10:弹窗几乎透明 |
| **主题主色** | **正文文字(=text_main,已合并)**、chip 选中填充、主按钮、描边… | **设成白色 → 所有正文变白,浅色面上"看不见字"**(图5/图7 就是这个) |
| 占位文字 / 提示文字 | 底栏未选中项、搜索框「搜索」、输入框提示 —— **不可配置**,由文字主色按 40% 不透明度算出来 | 改文字主色即可 |
| 强调文字 | 选中项、标题、tab 选中(底栏选中色走它) | 与主色分开时,选中态跟它走而不是主色 |
| 高亮文字 | 链接、搜索结果来源、展开/复制(默认蓝) | —— |
| 主按钮背景 / 主按钮文字 | 纯色按钮的底与字;**小组件按钮选中态**也取这两个键(填充忽略透明度);纯色按钮的边框线 = 主按钮背景的不透明版 | — |
### J.2 两个容易误判为"没走主题"的点(2026-09-27 核对)

1. **播放设置面板里"倍速/缩放看着对,跳过片头片尾/其他看着不对"**:核对下来 18 个选项键
   (倍速 7 + 缩放 1 + 片头片尾 3 + 播放器 2 + 其他 5)的**样式完全一致**
   (同一个 `bg_r_common_stroke_primary`、同样的 `gravity/singleLine/padding`),
   差别只来自**选中态**:倍速那行有选中项(代码换成 `bg_r_common_solid_select`),
   片头片尾/其他那几行当前没有选中项 → 看着像两套。不是漏改。
2. **弹窗/列表里的文字看着"没走主题"**:先把「主题主色」改成深色再看一遍 ——
   本版起正文(text_main)与主色合并,主色设成白色时,所有正文都会变成白字(浅色面上等于看不见),
   而没跟主题的少数位置仍是深色 → 于是"有的变了有的没变"。
