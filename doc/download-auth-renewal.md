# 下载重构与 HLS 鉴权续期（2026-10-01）

## 已落地

### 入队、存储与网络

- `EnqueueResult` 区分成功排队、重复、已下载、权限、解析、空间和目录错误；失败不再被计入重复任务。
- Android 11+ 有所有文件访问权限时写公共 `Download/MBox`；无权限时回退应用外部私有 Download，外部存储不可用时回退内部 files/downloads。权限按实际路径检查，撤权只影响公共目录任务。
- 仅 Wi-Fi 下的蜂窝/断网等待显示“已排队，等待 Wi-Fi”；点击继续可以排队，连接 Wi-Fi 后调度启动。
- Application 先注入 URL 解析器、嗅探器、上下文提供方，再启动下载 worker。

### 播放地址与请求上下文

- 当前集使用播放器的最终 URL 和完整请求头快照；其它集逐集解析，同源补播放器头，新的解析头覆盖旧值。跨域鉴权头由新解析结果或对应域的会话提供。
- 源解析优先执行 playerContent，裸 HTTP 地址也不会跳过爬虫返回的 UA/Referer/Cookie；父解析与后续 JSON 解析的 Header 合并。
- 解析需要 WebView 时先保存原 sourceKey/playFlag/episodeRawUrl 排队，执行侧串行嗅探。取消、超时及下一集通过 generation 检查隔离；嗅探保留自定义头和 Cookie。
- `DownloadRequestContextProvider` 由 app 组合根注入。宿主读取 MBox WebView 的最新 Cookie，提供课程页 Referer 和源/实际播放 UA；默认 UA 与 Media3 保持一致。学习通专用 UA、登录续期能力由源及真实播放上下文提供。
- 恢复及鉴权失败刷新 URL 和 Header 后一起提交，旧任务/过期大小探测结果不会回写。直链续传使用 If-Range 和 Content-Range 校验。

### HLS 会话续期

- `PlaylistSnapshot` 分离布局摘要和请求 URL 摘要。媒体序列、路径/顺序、范围、时长、discontinuity、key/IV、init 一致时，auth_key 等短时参数更新可保留完整分片。
- 无显式 media sequence 时按顺序与路径映射；布局不能安全匹配时暂停。磁盘只保留布局摘要、完成片、密钥摘要及 init，不整表持久化带 token 的分片地址。
- 401/403 立即刷新原源会话与清单；404/410 对原请求最多短重试两次（1 秒、2 秒），再刷新一次。刷新后同一稳定片仍 404/410，才进入永久缺片策略。
- 每次失败片仅一次续期；刷新后仍鉴权失败即暂停，确认缺片进入已有缺片/换线路策略，连续八片失败停止本轮。长任务可在后续分片再次续期。判定不依赖猜测 token 的有效期。
- 刷新成功只替换请求地址/范围/key/init 上下文，已有完整片保留；登录失效、布局改变、密钥实际字节改变、init 内容改变时暂停并显示原因。
- AES 轮换 key 的 id 等语义参数属于身份；常见鉴权参数可更新。恢复时核对 key 摘要和 init 内容，避免跨会话混片。
- 主清单优先选接近请求清晰度的变体，未指定时优先高画质；媒体清单或首片不可访问时尝试其它变体。已有进度时优先原变体并核对布局。
- 超星域及原课程页范围内共享两个下载槽；一般站点按当前设置支持 1–3 个并发下载。

### 调度与展示

- 设置新增“重启后自动继续下载”，默认关闭。开启只恢复原运行/排队/网络暂停任务；用户手动暂停继续保持暂停。每次恢复先刷新临时地址。
- 区分网络、鉴权、存储、源及合并错误，采用对应退避/续期/暂停策略。
- `DownloadExecutor` 收为执行门面与请求/大小探测，直链、HLS、合并、封装分别在 `DirectDownloader`、`HlsDownloader`、`HlsMerger`、`MediaRemuxer`。
- 任务运行在模块共享执行器。同一任务及同一目标等待旧执行退出后再继续。
- 下载页显示具体失败/暂停原因；“查看任务日志”调用已有 `DownloadFacade.getTaskLog`，查询与导出走后台执行器。

## 兼容说明

- 旧指纹仅含 URL/范围。普通未加密 TS 在完整旧指纹匹配时可迁移；旧 AES/fMP4 任务缺少足够的 key/init 身份信息，可能清理旧片重下。
- 新布局摘要一致时，单纯 URL 签名续期不清进度；未知密钥参数或 CDN 域改变按保守校验暂停。
- 带密钥、范围、init 或媒体序列的清单保留原始顺序，避免广告净化重排后错误推导 IV/隐式范围。
