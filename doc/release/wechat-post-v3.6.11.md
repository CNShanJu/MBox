# Mbox 重构，最新版本 v3.6.11

## 说明

软件本身为安卓应用，基于 TVBoxO-Mobile + AI 二开，代码开源，不收集或上传任何数据。软件只提供展示功能，不参与任何订阅源的制作、收集和发布。开发者不对任何订阅内容负责。仅用于个人学习和参考，安装后请于 24 小时内删除。

## 前置说明

上篇公众号写到 v3.6.8，这之间的 v3.6.9、v3.6.10、v3.6.11 三个版本攒着没发，这篇一次性补齐。

## 先说最要紧的

**从 v3.6.8 升级，务必先卸载旧版（或清除应用数据）再安装。** v3.6.9 动了本地数据存储的底层——数据库换了文件策略，旧数据没法直接沿用，覆盖安装会出问题。装之前把订阅地址、播放历史先记一份，本地备份文件不受影响。

## 版本说明

相较于上篇公众号的 v3.6.8，到 v3.6.11 的改动大致如下

01. IJK 内核整个删掉了（原来内置那套 FFmpeg 占十几兆），播放内核收敛到 Media3 + 系统内核，软解改由 Media3 的 FFmpeg 解码器顶上，Media3 一并升到 1.11.1。删完之后部分原本软解不动的片源，现在能软解了；安装文件也从 46MB 掉到 33MB 左右。
02. 新增边看边缓存和下集预缓存，默认开启，播放缓存的总闸现在是恒开的。
03. 本地包导入：订阅包、配置包可以直接在文件管理器里用 MBox 打开导入，不用再进应用里绕一圈。
04. 备份支持自定义命名、批量重命名；还原前会自动做一次系统临时备份（保留一小时），用来回退。
05. 订阅列表改成分组展示，能整组勾选做批量删除/更新，分组默认收起、自动展开当前项。
06. 直播这块：EPG 节目单下线了，直播频道配置做了优化，另外新增直播源导出。
07. 首页加了回到顶部。
08. 搜索修了一堆问题：内存不足导致的闪退、搜索无响应；搜索后播放、返回再搜索搜不到（现在改成连续两次失败才临时停用异常源，不再一失败就永久拉黑）；下拉刷新和上拉翻页打架、拉不出数据；夸克网盘这类源播放失败报「嗅探错误」。
09. 播放内核改成异步释放。某些片源卡死之后，再进播放页不会一直卡着了。
10. 修了播完一部片退出、再点其它片还播上一部的老毛病——起播前先让内核回到 idle，播放数据也改成显式注入。
11. 磁力、迅雷、种子直链可以直接播了；迅雷的 native 解析挪到独立线程并加了超时熔断，不至于把整个解析卡死。
12. 本机服务端口 9978 被占用时的处理重写了：起播前先试着把服务迁回默认端口，能迁就无感继续播；迁不回来，加载和失败提示里直接写清是哪个应用占着，点一下就能跳到那个应用的系统设置去关；关掉之后回到播放页会自动重试一次，不用重新点播放。
13. 详情页、详情抽屉的剧名可以长按看全名并一键复制，长剧名不用再盯着截断的两行猜了。
14. 详情抽屉里点海报大图不再报错，改成全屏查看，支持双指缩放，轻点或返回关闭。
15. release 包把 R8 混淆关了——之前启动闪退就是这么来的。
16. 更新弹窗的说明支持文字高亮，列表小圆点改成实心并且和文字对齐；长按选中文字不再闪一下蓝色，颜色跟着主题走。
17. 设置页把「磁力/荐片通道」挪到下载相关设置后面，分组清楚一些；背景设置里的「本地图片」「缓存图片」两个入口合并成「切换图片」弹窗。
18. 加载动画修了头部光晕一直抖、轮廓一顿一顿的问题，蒙版形变按帧重采样，光晕轨道也固定住了。
19. 播放器加载/失败提示改成纵向排布，图标、文字、多行文案不再挤成一团，端口占用提示单独占一行。
20. 细节：详情页选集/下载弹窗的字号跟全屏播放对齐，我的页面卡片边距、弹窗关闭按钮之类的位置也调了；另外画圈切集的手势下线了，左右两侧双击快进快退还在。
21. 应用层的 Java → Kotlin 迁移接着做了一部分，用户感觉不到，但确实是这轮干的活之一。

## 已知问题

- `.ass` 字幕的样式段解析还有缺陷，目前能保证出字，但字号、颜色、对齐这些样式不一定保得住。修起来要先拿到真实语料比对渲染，暂时先记着。

## 后续展望

1. 节日开屏壁纸。图床和大部分壁纸都备好了，代码里也留了口子，但自定义主题在开屏上会显示得奇奇怪怪，现在的想法是节日那天开屏默认给白底方便绘制，具体开发时间还是没定。
2. 配置的在线分享。导出 zip 再导入太绕，想做成给个分享码、朋友输码直接导入主题配置。局域网那块其实已经留了口子，链路差不多，缺的是具体实现。
3. 包体精简。删了 IJK 之后从 46MB 降到 33MB 左右，但还是觉得不够轻，想再往下压。
4. 部分组件想升到最新版本，目前只是想想。
5. Java 全部转 kt。工作量很大，也费钱，慢慢改。
6. 局域网服务那个网页，打算搞成独立的 vue 项目，还是设想阶段。

## 结尾

三个版本攒一起发，主要是中间那次底层动得比较狠（数据库文件策略 + 播放内核），得留点时间自己跑稳了才敢推。目前手上没再遇到显形的 bug，算是能站住的一个版本。

项目本身只做交流学习使用，不参与任何源的制作和分享，有 bug 欢迎铁铁们反馈。个人自测没法面面俱到，反馈我先记着，有机会再调。
