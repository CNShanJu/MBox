# MBox 更新说明(全版本)

本文件是 MBox **唯一**的更新说明来源。发版时只在标题下方、第一个 `## v` 版本节之前新增一节:

```md
## v3.6.12

### 新增功能

- **一句话说清用户能得到什么**:入口在哪、怎么用、和以前有什么不同。
```

写作要求见 `AGENTS.md` §九.2(新增功能 / 功能变更 / 移除停用 / 问题修复 / 体验与性能 / 兼容性注意),
开发者才需要的内容(依赖、模块、脚本、构建、commit)包进 `<!-- dev --> … <!-- /dev -->` 围栏,
App「检查更新」弹窗会自动剔除。

约定:

- **不再逐版本新建 `doc/release/release-notes-v<版本号>.md`**;唯一保留的历史文件是
  `doc/release/release-notes-v3.6.11.md`(仅当本文件缺该版本时兜底,内容不再维护)。
- 版本节按**新 → 旧**排列,节与节之间不插 `---` 分隔线;`## vX.Y.Z` 是本文件唯一的分节标记,
  发版正文会原样带上这一行(App 汇总说明时会去重,不会重复出现标题)。
- 取值方式(CI 与本地脚本一致):`node scripts/release-notes.js get v3.6.12`,
  打印该版本小节正文;写文件加 `--out <路径>`。缺该版本时退出码非零。
- v3.5.6 及更早的版本当时未单独留存说明,故本文件从 v3.5.7 起。

## v3.6.11

### 新增功能

- 详情页、详情抽屉的剧名支持长按查看完整名称，并可一键复制（长剧名不再只能看到截断的两行）。

### 问题修复

- 修复播放完一部片退出后，再点其它片播放的仍是上一部片的问题。
- 修复端口被占用时播放失败后仍自动重试一轮、白等约 40 秒的问题。
- 修复详情抽屉里点开海报大图会报错的问题（大图改为全屏查看，支持双指缩放，轻点或返回关闭）。
- 修复加载动画头部光晕持续抖动、轮廓形变一顿一顿的问题。

### 功能优化

- 本机服务端口（9978）被占用时处理更明确：
  - 起播前会先尝试把服务迁回默认端口，成功则无感继续播放；
  - 迁不回来时，加载与失败提示里直接写明"端口被哪个应用占用"，点一下即可跳到该应用的系统设置页去关闭；
  - 关闭占用方后回到播放页会自动重试一次，不需要重新点播放。

### 部分 UI 调整

- 播放器加载/失败提示改为纵向排布，图标与文字、多行文案之间不再挤在一起；端口占用提示单独成行。

## v3.6.8

### 新增功能

- 搜索页新增“常用收藏”：长按历史搜索词即可收藏，点击收藏词直接发起搜索，长按收藏词可删除；清空搜索历史不会影响收藏。
- 本地备份支持“系统临时备份”：用本地备份文件还原前，会先自动保存当前设置与播放数据，还原失败可回滚到还原前的状态；系统备份在列表中有单独标识，不能手动删除。
- 局域网配置传输支持扫码连接：扫到有效二维码后直接连接，不必再手动填写地址；服务运行时，标题行右侧提供“控制台”文字入口。
- 支持把手机正在播放的视频推送到电脑浏览器观看，画面按当前的净化设置处理，网页播放失败会自动重试。
- 主题新增“开屏背景”：可以跟随主题底色、自选纯色或指定图片，图片支持调整位置和大小，还能选择是否在图片上继续播放开屏动画；开屏背景随主题一起切换。
- 局域网服务页新增投屏面板：可以看到当前投送到的设备与状态并停止投送；“在线设备”列表会定期刷新，不用退出重进。
- 点击后台播放通知可直接回到正在播放的页面；应用被系统回收后点通知，会先完成启动再打开。

### 功能变更

- “忽略证书错误”改为全站开关：开启后对所有网站生效，不再需要逐个填写域名，默认仍为关闭。
- 播放设置新增“长按倍速”，默认 3.0x，可在播放设置面板或设置页改为 2.0x、4.0x、5.0x。
- 在线播放的“广告过滤”改为与渲染方式一致的按钮样式，只显示当前档位。
- 后台播放默认关闭，需要时可在设置中重新开启。
- 搜索结果通栏卡片改为横版并自动按屏幕宽度调整列数；来源抽屉的条目间距更紧凑。
- 播放器与列表各处的加载动画统一为完整显示，不再被裁切，各处大小一致。
- 主题的圆角与描边改为“只保存改动过的项”，没改过的跟随默认值：以后调整默认圆角，只改过颜色的自定义主题会一起更新。
- 主题编辑器的颜色项直接显示色值，点击即可在取色板里取色或输入十六进制颜色；透明度与描边粗细仍按数字填写。
- 默认圆角略微调整：常规按钮更圆（14→24dp），下载页与本地视频的小封面圆角 10→12dp；圆角说明也改成按界面位置描述，更容易找到要调的那一项。
- 浏览器投屏新增“重载播放”：声音或画面异常时可以重载，并保留当前进度、暂停状态与倍速。
- 网页端 HLS 播放升级到 hls.js 1.7.3 light，改善 AAC 与 HE-AAC 音频的兼容；恢复进度时直接加载对应的分片。
- 详情页、字幕等处的文字选择与光标跟随主题文字色，选区背景改为不透明纯色，浅色主题下也看得清。
- 播放器控制条的总时长与当前位置宽度固定，数字变化时不再左右抖动。

### 问题修复

- 详情页切换线路不再沿用上一集的选中状态，点击新的剧集才会切换播放。
- 字幕搜索与选择更稳定，支持更多字幕格式，播放过程中会自动刷新字幕。
- 下载时只有与当前播放剧集一致的剧集才会复用播放地址，避免同名剧集用错地址。
- 纯文字按钮（复制、展开、文字动作等）点击时不再出现圆形波纹或按压底色。
- 删除下载后，只有该剧集的所有来源与归档记录都已删除时才清理共享海报；下载记录文件还有待恢复的中间状态时，不再被当成空记录导致列表丢失。
- 订阅地址没有写 `http://` 时不再拼错地址，避免这类订阅打不开。
- 本地备份可以兼容读取旧版的开屏图片条目，还原后不会再尝试安装已停用的独立开屏图片。
- 本地图片重复绑定到同一控件时会保留正在进行的加载，多个背景图同时导入不会互相覆盖临时文件。
- 选择类弹窗在删除条目后不再被压成固定高度，内容多时正常滚动。

### 注意事项

- 局域网服务与电脑网页推送改动后，需重启一次应用才会按新方式生效。
- “忽略证书错误”对网页浏览立即生效，其他网络请求需重启应用后生效。
- 旧主题文件在读取时会自动迁移到新格式，保存后才按新格式写入。

## v3.6.7

### 功能与改进

- 新增加载动画“大白鹅”“四叶草”“兔子”“鲨鱼鳍”，并调整动画在加载弹窗和下拉刷新中的显示。

- 减少播放和直播自动恢复过程中的中间提示，尝试结束后再显示简短的失败建议。
- 调整快捷搜索与详情弹窗在矮屏上的内容展示；业务日志打开后定位到最新记录。

## v3.6.6

### 功能变更

- 下载默认交给 1DM+，直接传递当前集的原始播放地址和请求头。需要批量选集与应用内下载管理时，可在设置中开启“使用内置下载”。
- 收藏与观看历史支持长按多选、全选、取消全选及确认后批量移除。“我的”页恢复收藏入口，订阅管理移至设置页。
- “我的”页在当天显示节日或节气名称；支持烟花的节日在主动启动应用、首页出现后播放错峰烟花。
- 证书例外改为指定单个网站，开启时需填写精确域名；其他网站继续校验证书。

### 改进

- 优化开屏期间的配置与插件加载，减少启动卡顿。主题、订阅等设置生效引起的内部重启，不再重复触发启动烟花、自动更新提示和“上次看到”。
- 更新下载中断后保留进度，重新打开应用可继续；下载期间显示后台进度通知。
- 加宽首页搜索框，调整“上次看到”气泡的位置，减少与直播入口重叠。
- 日志内容区可左右滑动切换业务与错误日志；缓存管理增加运行日志统计与清理。

### 问题修复

- 修正订阅页横向滑动时可能误触条目、切换来源的问题。
- 调整直播播放清单更新、部分视频地址兼容处理及画中画控件显示。
- 改善在线字幕缓存、下载海报重试及下载文件迁移失败时的数据保留。

## v3.6.5

**新增功能**
- 投屏到电视(局域网 DLNA):点播、直播和本地视频都能搜索同一 Wi-Fi 下的电视并直接投屏,不用在电视上输入配对码;搜不到时可以手动填电视地址直连,投到电脑浏览器的方式保持不变。
- 「清空缓存」改为独立的「缓存管理」页:按「图片缓存 / 可清理的副本 / 应用运行文件」列出各处占用,长按可多选后一次清理;下载、收藏和观看记录不在清理范围内。
- 局域网配置导入导出支持扫码:一台手机出示含地址与配对码的二维码,另一台扫码即连并挑选要导入的类别;新增「已连接设备」页,可查看在线状态与最近活动,也能踢出设备。
- 「我的」页新增「检查更新」入口;播放设置里新增「广告过滤」开关(默认开启,只对在线播放显示),画面异常时可以关掉后重播。
- 新增「紫色」深色主题,原来的 moonlight 更名为「深紫」。

**功能变更**
- 局域网服务的开关移到「局域网服务」页,与访问地址、配对码放在一起;关闭会立即停止局域网访问并清除已配对设备(开启仍需重启一次)。
- 全屏播放的时间与横竖屏切换键收进控制栏,随控制栏一起显隐;播放设置面板里的「横竖屏」按钮移除,详情页预览时该键用于进入全屏。
- 「我的」页移除「收藏」入口(首页的收藏按钮照旧),「关于」页底部改为「免责声明」入口。
- 新安装默认使用 SurfaceView 渲染画面,已经在用的设置保持原样,也可以在播放设置里改回。

**问题修复**
- 从观看历史或首页「上次看到」进入时,直接用记录里的剧集信息接着播放,不必等详情加载完再点一次。
- 换源、换集时,较晚返回的旧解析结果不再覆盖当前播放,不会再出现「换了源却播回旧地址」。
- 更新包下载更可靠:中途换线路续传不会把两个来源的数据拼成坏包,下了一半或校验不过的安装包会自动重下,旧版本留下的安装包也会清理。
- 检查更新的弹窗不再重复显示版本标题,也不会把跨版本数量说错。
- 投屏失败时会说明原因(播放源出错、返回的不是视频、格式认不出来);修复部分主题下播放弹窗与全屏系统栏状态不一致的问题。

**体验与性能**
- 启动更快:开屏动画与首页数据同时准备,首页等动画结束才装配,进首页不再先空一下、卡一下;开屏动画也会跟随明暗主题。
- 搜索更快:同一个来源在一轮搜索里只请求一次,慢的来源不再堵住其它来源,过期的那一轮结果直接丢弃;搜索页词条的上下留白也收紧了。
- 播放器双击画面左右两侧可前后跳 10 秒(连续双击叠加),并给出弧形区域与触点涟漪提示;全屏按键与时间避开屏幕挖孔,竖屏全屏顶部不再多出一条空白;窄屏下时间与进度条自动换行,进度条不会被挤到拖不动。
- 首页「上次看到」气泡停留更久,先显示片名开头再滚动展示,点整块气泡即可接着看。
- 加载动画可以在设置里长按放大预览。

## v3.5.9

### 新增功能
